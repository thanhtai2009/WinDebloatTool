aria2 - bundled third-party program
===================================

This folder contains UNMODIFIED official Windows builds of aria2, a separate program
used by WinDebloat Tool (via its command line) for multi-connection downloads.
WinDebloat Tool's own code is MIT licensed; aria2 is licensed under the GNU General
Public License version 2 or later (see COPYING), with an OpenSSL linking exception
(see LICENSE.OpenSSL). Shipping both in one archive is "mere aggregation" (GPLv2 sec. 2):
the MIT code does not link to aria2 and aria2 is not modified.

Project     : https://aria2.github.io/  -  https://github.com/aria2/aria2

To update: replace x64\aria2c.exe / x86\aria2c.exe with a newer official release and update
this file. The tool also uses an aria2c.exe found in tools\, next to the script, or on PATH.
